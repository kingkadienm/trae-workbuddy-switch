- 新增 `GET /v1/video/models`、`POST /v1/videos`、`GET /v1/videos/:id`，沿用 WorkBuddy 网关端口与区域 Key。
- 按对应区域上游 `/v3/config` 读取视频模型及能力，校验时长、分辨率、比例、音频与首帧参数。

## 如何接入

视频接口默认使用 WorkBuddy 网关的 `57891` 端口；已有配置可能使用 `7863` 等自定义端口，以网关设置为准。使用对应区域、无配额限制的 `sk-wb-…` Key。

火宝增强版可选择视频供应商 `custom`：提交路径 `/v1/videos`，任务 ID 字段 `id`；轮询路径 `/v1/videos/{{task_id}}`，完成状态 `completed`，完成结果路径 `upstream.data.data[0].url`。完整表单和请求体见接入指南。
